Privacy Policy

Last updated: April 13, 2026

1. Data Collection

Diagramma does not collect, store, or transmit any personal data or document content. No analytics, tracking, or telemetry is used.

2. Document Access

Diagramma accesses only the currently open Google Docs document, and only when you explicitly interact with the add-on (opening the sidebar or editor). It reads diagram code blocks and writes rendered images back into the same document. No data leaves your browser or the Google Docs environment.

3. Third-Party Services

Diagramma loads the editor UI from GitHub Pages (fogha.github.io/diagramma). This is a static site with no server-side processing. Diagram rendering is performed entirely in your browser using the Mermaid.js library — no diagram content is sent to any server.

4. Cookies and Local Storage

Diagramma does not use cookies, local storage, or any client-side persistence mechanism.

5. Data Sharing

Your data is never shared with third parties. Diagramma has no backend servers, databases, or external API calls.

6. Children's Privacy

Diagramma does not knowingly collect information from children under 13.

7. Changes to This Policy

We may update this Privacy Policy from time to time. Changes will be posted on this page with an updated date.

8. Contact

For privacy-related questions, open an issue on GitHub.
