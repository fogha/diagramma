How to use Diagramma and get help

Getting Started

  1. Open a Google Doc and go to Extensions > Diagramma > Open Editor.
  2. The sidebar will show all diagram blocks found in your document.
  3. Write a Mermaid diagram in a fenced code block:
    ```mermaid
    flowchart TD
      A --> B
    ```
  4. Click Edit on a block to open the full editor with live preview.
  5. Click Replace with PNG to insert a rendered image into the document.

Supported Diagram Types

Diagramma supports all Mermaid diagram types including flowcharts, sequence diagrams, class diagrams, state diagrams, ER diagrams, Gantt charts, pie charts, and more. See the Mermaid documentation for the full syntax reference.

Frequently Asked Questions

The editor doesn't show my diagram

Click the Retry button in the preview panel, or check your Mermaid syntax for errors — the error message will appear in the preview area.

Can I edit a PNG diagram back to code?

Yes. When you replace a code block with a PNG, Diagramma stores the original source in the image metadata. Click Edit on a PNG block in the sidebar to reopen it in the editor.

Does Diagramma send my data anywhere?

No. All rendering happens locally in your browser. No document content is sent to any server. See our Privacy Policy.

Report a Bug

Open an issue on GitHub with a description of the problem, your browser, and any error messages from the browser console.
